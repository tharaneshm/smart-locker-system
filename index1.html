About the Project

This project was developed by pre-final year Electronics and Communication Engineering (ECE) students dedicated to bridging the gap between hardware architectures and robust software applications. The focus of this development is to demonstrate professional-grade security implementations on accessible hardware.

The core system utilizes an ATmega328P microcontroller architecture, integrating matrix membrane controls, precise servo actuation, and secure local device memory for logging capabilities. By stepping away from simple hobby-level implementations, this system focuses on power optimization, robust state-machine logic, and physical hardware interrupts.

Supported by an NPTEL certification in Java, this desktop dashboard acts as the bridge. It communicates flawlessly over serial protocols to provide an administrative overlay, allowing for real-time monitoring and parameter configuration without requiring hardware modifications.
